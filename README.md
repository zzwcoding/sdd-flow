# sdd-flow

**一套跑在 AI 编程助手里的 SDD 全流程手册**

*从一句粗糙的 PRD,到可运行、有账本、有门禁的交付。*

核心断言:**文档里包含一切,AI 做的只是把文档翻译成代码。**

- 八阶段流水线(逼问式需求 → 深模块 → 机器校验的规格 → 拆票 → 双档执行 → CI 守门 → 架构体检),每阶段有产物、有门禁、有状态机,不过闸不前进
- **spec gate**:200 行零依赖校验脚本进 CI,机器核对账本(依赖无环、验收绑测试、已完成→测试必须存在),23 项自测全绿
- 需求逼问有 **11 维防漏清单 + A/B 问题分流**;两档执行:学习项目人把控(learn-by-rebuild),生产项目主子 agent 全自动
- 新窗口**零记忆恢复**:进度全在磁盘账本,不在聊天记录

完整文档、交互式全流程地图与最新代码见 → **[zzwcoding/skills/sdd-flow](https://github.com/zzwcoding/skills/tree/main/sdd-flow)**
